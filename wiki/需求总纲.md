## 纯IO直连控制架构

为缩小设备体积、降低硬件复杂度，彻底弃用继电器，采用 **ESP32 IO口直连原车钥匙PCB** 的极客方案。

### 安全接线与防烧毁逻辑

原车钥匙为 3V 供电，ESP32 信号引脚输出为 3.3V。为绝对避免反向灌入电压烧毁钥匙主板，采用 **"开漏输出（高阻态）"** 策略：

- **接线规范**：ESP32 主板的 GND 必须与钥匙的 GND 连通（共地）。ESP32 的对应 GPIO 针脚直接连到钥匙的信号触点（可与蓝牙盒子并联）
- **平时闲置（模拟按键释放）**：引脚设置为 `OUTPUT_OPEN_DRAIN` + `digitalWrite(HIGH)`，呈高阻态，相当于物理断开，对原车电路零干扰
- **动作触发（模拟按键按下）**：`digitalWrite(LOW)`，相当于把信号线直接接地

### ESP32 安全引脚分配

| 车辆功能 | 动作时序 | ESP32 安全引脚 |
|:--- |:--- |:--- |
| 锁车 | 触发 LOW 一次 (300ms) | GPIO13 |
| 解锁 | 触发 LOW 两次 (间隔100ms) | GPIO13 |
| 左鹰翼门 | 触发 LOW 两次 | GPIO14 |
| 右鹰翼门 | 触发 LOW 两次 | GPIO25 |
| 后备箱 | 触发 LOW 两次 | GPIO26 |
| 前备箱 | 触发 LOW 两次 | GPIO27 (App端需设二次确认) |

> ⚠️ 锁车和解锁共用 GPIO13，通过时序区分（单次 vs 两次），代码需加防竞争状态机

## 硬件电源规划（24小时不断电）

```
汽车点烟器（ACC着车有电）
   │
   ▼
DC-DC 降压模块（限流充电）
   │
   ▼
【1S大电流磷酸铁锂保护板】 → 52Ah 磷酸铁锂大单体（标称 3.2V）
   │ (保护板欠压 2.5V 自动切断负载，防电芯过放)
   ▼
DC-DC 升压模块（升至 5V，持续最大 3A）
   │
   ▼
ESP32 主控板 + ML307R 4G 模块（统一 5V 供电）
```

## 远程控制方案

- **通信硬件**：ESP32 UART2 直连 ML307R（ASR1602 芯片，支持 AT 指令集透传）
- **云端服务**：自建 Mosquitto MQTT Broker（不用巴法云）
- **控制端（iOS 专属优化）**：通过 HTTP→MQTT 桥接，利用 iOS 快捷指令发送网络请求，支持 Siri 语音控制

## 兜底自动锁车（防忘锁机制）

- ESP32 内部设置一个 10 分钟倒计时器
- 收到并执行 unlock 指令后，计时器开始倒数
- 若计时期间收到 lock 指令，则终止计时器
- 若计时器归零，ESP32 自动执行一次锁车动作
- 防误锁心跳：提供 heartbeat 指令，快捷指令中可配置一键重置 10 分钟倒计时

## 已否定路线

| 路线 | 原因 |
|------|------|
| Tesla 官方 API | 无主账号，无法获取 Token |
| OVMS3 | Model X 支持极差，远程控制功能均标注 Not currently supported |
| 直接逆向 HVAC CAN | 协议未知，特斯拉网关可能过滤，防重放机制不确定 |
| 模拟开门 | 效果不理想 |
| 长期开启露营模式 | 耗电，不符合使用习惯 |
| 继电器方案 | 体积大、功耗高、复杂度高，改用纯IO直连 |
