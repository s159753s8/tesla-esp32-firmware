# v3.0 固件更新记录

> 2026-06-02 更新：改用开漏输出，保护钥匙主板

---

## 主要变更

### GPIO 控制策略

| 版本 | GPIO 模式 | 平时状态 | 触发状态 |
|------|-----------|---------|---------|
| v2.2 | OUTPUT+HIGH/LOW | 3.3V | 0V |
| **v3.0** | **OUTPUT_OPEN_DRAIN** | **高阻态** | **LOW（接地）** |

### 开漏输出

- 平时：`digitalWrite(HIGH)` = 高阻态，物理断开
- 动作：`digitalWrite(LOW)` = 接地，模拟按键按下
- 绝对禁止输出3.3V到钥匙信号线（钥匙是3V供电）

## 新增函数

```cpp
// 单次脉冲：LOW -> 等待 PRESS_MS -> 恢复 HIGH
void triggerOnce(int pin) {
  digitalWrite(pin, LOW);
  delay(PRESS_MS);
  digitalWrite(pin, HIGH);
}

// 双次脉冲
void triggerTwice(int pin) {
  digitalWrite(pin, LOW);
  delay(PRESS_MS);
  digitalWrite(pin, HIGH);
  delay(INTERVAL_MS);
  digitalWrite(pin, LOW);
  delay(PRESS_MS);
  digitalWrite(pin, HIGH);
}
```

## 全局参数

```cpp
const int PRESS_MS      = 300;  // 按下时长
const int INTERVAL_MS   = 100;  // 双击间隔
const int AUTO_LOCK_MS  = 600000; // 10分钟自动锁车
```

## 指令清单

### 实际控制指令
- `lock` → GPIO13 triggerOnce
- `unlock` → GPIO13 triggerTwice
- `left_open` → GPIO14 triggerTwice
- `right_open` → GPIO25 triggerTwice
- `trunk_open` → GPIO26 triggerTwice
- `frunk_open` → GPIO27 triggerTwice
- `heartbeat` → 重置计时器

### 测试指令（不实际操作GPIO）
- `test_lock`、`test_unlock`、`test_left`、`test_right`、`test_trunk`、`test_frunk`

## 安全机制

- 防竞争锁：actionLocked 布尔变量，动作执行中忽略所有新指令
- 开漏输出：OUTPUT_OPEN_DRAIN 模式，平时HIGH=高阻态，LOW=接地
- 绝对禁止输出3.3V
